# VanVirasat

**Discover Tribal India. Experience Living Heritage.**

VanVirasat is a tourism platform concept beginning in Dungarpur and southern Rajasthan. It aims to connect visitors with thoughtfully curated nature, heritage, food, craft and community-led experiences while supporting local guides and partners.

## Current status

The repository contains a responsive landing-page prototype with:
- Brand-led homepage, story and responsible tourism sections
- Example journey cards and indicative prices
- Destination, date, experience and traveler selectors
- Inquiry form that prepares an email message
- Mobile-friendly styling and basic search metadata

**Important:** This is a prototype, not a production booking or payment system. Package names and prices are illustrative and must be validated before publishing. The inquiry form does not store data on a server; no payment is taken and no booking is confirmed by this prototype.

## Tech stack

- Next.js App Router
- React + TypeScript
- Tailwind CSS v4
- Lucide icons

## Run locally

Requirement: Node.js 20.9 or later.

```bash
npm install
npm run dev
```

Open http://localhost:3000.

For a production build:

```bash
npm run build
npm start
```

## Roadmap

1. Validate actual experiences, day-wise itineraries, local partners, prices, inclusions and operating policies.
2. Add database-backed packages, date availability, capacity and bookings.
3. Add booking lookup and an admin dashboard.
4. Integrate a secure payment gateway with server-side verification and signed webhooks.
5. Add confirmations, cancellations/refunds, privacy policy and terms.
6. Test mobile layout, accessibility, security and production deployment.

## Safety and responsible tourism

Publish community experiences only after consent and verification. Respect privacy and cultural protocols, compensate local partners fairly, be transparent about inclusions, and use appropriate safety and child-protection practices.
